## Ключевая идея модели

Карта **не зависит от актора**: она описывает способности всей экосистемы (Банк России — эмитент
и оператор платформы, банки-посредники, торговые и B2B-компании, государство), а не отдельного
участника. Для конкретного клиента из референсной карты формируется ракурс (view) с матрицей
ответственности, оценкой зрелости и gap-анализом.

Такая конструкция (одна референсная модель + представления для стейкхолдеров) позволяет:

- не дублировать модель под каждый сегмент (~60–70% способностей совпадают у всех акторов);
- синхронно обновлять знания при изменении нормативной базы и правил платформы;
- сравнивать акторов между собой на единой шкале.

## Структура карты

11 доменов:

1. Эмиссия и управление платформой обращения *(экосистемный — Банк России)*
2. Обслуживание владельцев цифровых рублей
3. Конвертация форм рубля (включая управление ликвидностью для банков-посредников)
4. Выполнение платежей и переводов (P2P, B2C, B2B, C2G/B2G)
5. Выполнение государственных выплат *(экосистемный — государство)*
6. Применение программируемых условий расчётов *(ключевой домен для консалтинга)*
7. Выполнение операций без сети (офлайн) *(экосистемный, в разработке)*
8. Обеспечение комплаенса и безопасности
9. Учёт, тарификация и отчётность
10. Технологическая интеграция и эксплуатация
11. Развитие продукта и рынка

Подробное описание устройства и решений — в начале `capabilities-guide-ru.md`.

## Как использовать

1. **Как референс** — для погружения в тему и навигации по домену. Начните с доменов 3, 4, 6.
2. **Как основу для профиля клиента** — выберите релевантные способности, добавьте матрицу
   ответственности (accountable / participant / consumer / none) и оценку зрелости.
3. **Как основу для gap-анализа** — сопоставьте текущую зрелость клиента с требованиями
   регулятора (этапы подключения по 248-ФЗ: 2026 — крупнейшие банки и продавцы 120+ млн ₽,
   2027 — банки с универсальной лицензией, 2028 — все остальные).

## Статус и актуальность

Тема быстро меняется: нормативная база, тарифная модель и функциональность платформы ЦБ
обновляются регулярно. Карта отражает состояние на момент последнего коммита; способности,
которые ещё не реализованы (офлайн-режим, конвертация наличных, программируемые условия
в полном объёме), помечены как целевые.

Ключевые нормативные ориентиры: 340-ФЗ (2023, правовая основа), 248-ФЗ (2025, этапы
подключения), 303-ФЗ (2025, расчёты через Федеральное казначейство).
